# 数字疗法：技术与临床审计

## 目录

1. 产品定性
2. 临床证据
3. 使用与安全
4. 快速问题

## 1. 产品定性

区分健康教育、疾病管理、辅助治疗和独立治疗。判断软件是否作出治疗声称、是否需要处方、是否与药物/器械组合，以及医生能否独立复核输出。

## 2. 临床证据

检查对照组、盲法可行性、主要终点、最小临床重要差异、依从性、失访、随访持续性和同期治疗。等待名单或低强度对照可能夸大效应；下载量不等于治疗完成或疗效。

## 3. 使用与安全

- 激活、周活、疗程完成和长期留存；
- 不良事件、危机升级和人工干预；
- 版本变化是否改变治疗内容；
- 隐私、未成年人、可及性和数字鸿沟；
- 医生工作流、处方和患者支持成本。

## 4. 快速问题

1. 治疗成分、作用机制和适应症?
2. 主要终点相对活性对照的效应量?
3. 激活、完成、依从和 3/6/12 月留存?
4. 危机或不良事件如何升级?
5. 谁处方、谁付款、谁承担患者支持?
6. 版本更新如何验证和管理?
