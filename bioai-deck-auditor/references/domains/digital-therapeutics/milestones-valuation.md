# 数字疗法：里程碑与估值

## 1. 里程碑链

```text
行为机制 → 可用性 → 临床信号 → 监管路径 → 支付/处方 → 激活与完成 → 续约/真实世界效果
```

## 2. 估值

监管前使用情景/里程碑法；商业化后按合格患者、处方、激活、完成、净价、续约和支持成本建模。不要以下载量或注册用户直接替代付费疗程。

区分：

- 企业/保险合同收入；
- 按处方或疗程收入；
- 服务和患者支持成本；
- 与药企合作的里程碑收入。

## 3. 特有陷阱

- 监管获批但无支付和处方动力；
- RCT 参与度高于真实世界；
- 把活跃度当临床疗效；
- 将通用内容包装成专有治疗机制；
- 患者支持成本被排除在毛利之外。
