## 1. 里程碑链

```
样机/原理验证 → 型式检验 → 临床评价/临床试验 → 注册受理 → 拿证 → 物价编码 → 招标进院 → 放量
                                                                              ↓
                                                              【若适用】纳入集采 → 价格、量和份额重估
```
**关键认知**:拿证不是商业终点；支付、采购、进院、回款和潜在集采都会影响现金流。市场规模、用量、竞争者数量与标准化程度可作为集采暴露线索，但不能推出必然纳入。

## 3. 集采暴露与情景分析

对进入或可能进入带量采购的品类必须评估集采暴露；明确不在适用范围的产品记录判断依据。

### 数据采集

对目标品类记录：正式公告链接、批次与地区、最高有效申报价/中选价、加权平均价格变化、约定采购量、中选规则、竞品数量和执行日期。不同品类、批次或采购层级的数据不得直接互换；媒体汇总的平均降幅只能作线索。

### 集采的估值含义(必须写进模型)

1. **对有现实集采暴露的品类做集采情景。** 使用目标批次/相邻品类的价格与放量数据，不机械打固定折扣
2. **"以量换价"是真的**:降价换来的是全国铺量。所以要重算:`集采后价格 × 集采后放量` vs `集采前价格 × 集采前用量`。**有些品种总收入反而增长,有些腰斩**——取决于原来的渗透率
3. **中选与否影响份额**:未中选的影响取决于采购规则、非约定量、院外和自费市场，不自动设为零。
4. **暴露是概率问题**:市场规模、临床用量、标准化程度和竞争数量增加政策关注可能性，但不能推出“必然集采”。

### 审计动作:集采暴露评估(必做)

| 问题 | 判断 |
|---|---|
| 该品类已被集采了吗? | 已集采 → 用集采后价格建模,别无选择 |
| 未集采 → **它有多大概率被集采?** | 看市场规模、用量、竞争者、标准化程度和政策方向；用情景概率表达，不写“早晚必然” |
| 有没有技术壁垒/独家性? | 技术差异、临床价值、供应能力和竞争数量可能影响中选与降幅，需按品类核实 |
| 是否有集采外的市场? | 民营医院、消费医疗、自费、出海——**但注意:集采范围正在向基层和民营扩展** |

**2026年趋势(需核实最新)**:集采正从"唯低价"转向"多元评审"(竞价/询价/带量价格联动/**综合评议**四类)。**综合评议**针对技术壁垒高、创新属性强的高值耗材,由专家对质量、临床价值、技术先进性打分——**这对真正有技术壁垒的公司是利好**,要在报告中区分对待。

## 4. 回款账期(现金流杀手,常被严重低估)

**公立医院回款周期通常 6个月以上**,应收账款的资金成本会实质性抬高企业的运营压力。

**审计动作:**
- 索取**应收账款周转天数(DSO)**。**这个数字比收入更能说明问题**
- 一家账面收入增长但DSO持续拉长的器械公司,**现金流可能在恶化**
- 国家医保局正在推"医保与企业直接结算"(以集采品种为重点)——**这是利好,但覆盖范围有限,需核实公司的品类是否在内**

**⚠️ 这一条与 health-saas 子领域相通:任何卖给公立医院的业务,都必须做账期审计。**

## 5. IVD 特殊性

IVD(体外诊断)在器械框架下有额外的关卡:

| 环节 | 说明 |
|---|---|
| **仪器 + 试剂的绑定** | 商业模式是"卖仪器送/低价卖,靠试剂赚钱"(剃刀-刀片模式)。**审计:装机量和试剂消耗量的比值是多少?装机不用=僵尸装机** |
| **试剂需单独注册** | 每个检测项目的试剂可能要单独注册 |
| **室间质评** | 需通过质量控制评价 |
| **检验科采纳** | 检验科有自己的采购和流程习惯,切换成本高(既是壁垒也是进入障碍) |
| **⚠️ 试剂集采** | 若目标试剂已纳入或高度暴露，按对应批次的价格、约定量和中选规则重算剃刀-刀片模型 |
| LDT路径 | 实验室自建项目,监管路径不同 |

**IVD的核心审计问题:装机量 vs 试剂消耗。** deck爱讲装机数,但**装机不产生收入,试剂才产生收入**。要单机试剂消耗量。

## 6. 估值方法选择

| 公司位置 | 方法 | 关键调整 |
|---|---|---|
| 拿证前 | **rNPV** | 按第2节连乘 |
| 拿证后未进院 | rNPV过渡 | 扣除编码+进院两关 |
| 已放量,**未被集采** | DCF/可比 | **必须对集采做情景分析**:若被集采(降幅按第3节),估值还剩多少? |
| 已被集采 | DCF | 用集采后价格和放量后的实际数据 |

**★ 必做的情景分析**:
```
情景A(基准):不被集采 → 当前价格 × 增长
情景B(集采中选):目标批次价格变化 × 约定量/份额变化 → 收入与毛利净影响
情景C(未中选):按采购规则估计公立、院外、自费和海外剩余份额
```
若产品有明确集采暴露而 deck 只给情景 A，标为重要估值证据缺口；严重度取决于暴露时间和收入占比。

## 7. 特有陷阱

**① 集采盲区**:deck只字不提集采 → 要么无知,要么隐瞒。**这是最常见也最贵的遗漏**
**② "我们的品类不会被集采"**:追问依据。技术壁垒?独家?——**要具体,不能是"我们很创新"**
**③ 装机量幻觉(IVD)**:装机≠收入。看单机试剂消耗
**④ 应收账款**:账面收入好看,现金流在恶化。查DSO
**⑤ 渠道依赖**:器械高度依赖经销商。**经销商集中度是多少?他们会不会倒戈?**
**⑥ 硬件毛利真相**:高毛利可能来自耗材组合、软件、渠道口径或成本漏计。宣称 80%+ 时拆分 BOM、制造、质保、渠道、实施、NRE 与软件收入，不因行业标签直接判错。
**⑦ 反腐与合规**:医疗设备招采是反腐重点领域。**渠道费用的合规性是实质风险**
