# 合成生物学：里程碑与估值

## 1. 里程碑链

```text
实验室样品 → 中试连续批次 → 客户规格验证 → 示范产线 → 目标规模良率 → 长协/重复订单 → 稳定现金流
```

## 2. 估值

早期项目用里程碑和情景法；量产后以正常化产能、利用率、单位经济和资本开支做 DCF/可比。不要按“平台可生产 N 种分子”把所有候选产品相加。

情景至少覆盖：

- 放大后指标下降；
- 原料/能源价格变化；
- 建厂延期和资本开支超支；
- 客户认证延迟；
- 产品售价被成熟路线压低。

## 3. 估值陷阱

- 用实验室成本替代商业全成本；
- 用设计产能替代实际良率与利用率；
- 把 MOU 当长期承购；
- 忽略营运资金、库存和废物处理；
- 平台故事与单一产品收入混用估值倍数。
