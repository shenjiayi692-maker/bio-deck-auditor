# 合成生物学：技术审计

## 目录

1. 技术链
2. 放大风险
3. 产品与市场
4. 快速问题

## 1. 技术链

逐产品拆成底盘、通路设计、菌株/细胞系、发酵、分离纯化、质量规格和终端应用。平台能力必须落到具体产品的产率、滴度、转化率、稳定性和批间一致性。

## 2. 放大风险

摇瓶或小罐性能不等于工业规模：

- 放大后的传质、热量、剪切、污染和代谢负担；
- 菌株遗传稳定性和连续代次；
- 下游纯化收率、溶剂和废物处理；
- 原料、能源和副产物价格敏感性；
- 设备利用率、良率和停机清洗。

要求同一工艺在目标规模的连续批次数据，不只看单次最佳批。

## 3. 产品与市场

区分高价低量特种品与低价大宗品。技术可行不代表经济可行：比较生物路线与石化、提取、化学合成或成熟发酵路线的全成本、规格和客户认证周期。

## 4. 快速问题

1. 当前数据来自多少升规模、多少连续批次?
2. 目标规模下的产率、滴度、转化率和全成本?
3. 下游纯化占成本多少?
4. 客户验证的是样品、规格还是已签长期采购?
5. 原料和售价变化 20% 时毛利如何?
6. 核心菌株、工艺 know-how 和 FTO 如何保护?
