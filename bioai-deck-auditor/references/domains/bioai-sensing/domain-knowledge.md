# 生物 AI 感知：技术与证据审计

> 配合 `references/common/audit-tech-common.md`。本包覆盖摄像头/rPPG、接触式 PPG、多模态生理信号、无袖带血压、疾病风险与情绪/心理状态推断。具体监管先例运行时查一手数据库。

## 1. 先定义被测量对象

对每条宣称画出：原始物理信号 → 预处理 → 特征/模型 → 输出 → 金标准 → 使用决策。

- 光学信号可反映皮肤随血容量变化的微弱变化，但运动、光照、压缩、设备、肤色、遮挡和灌注都会影响信噪比。
- “模型能预测”不等于“直接测量”。血压、疾病风险或内在心理状态通常包含较长推断链，需额外验证构念效度和临床效度。
- 多输出模型不能共享一个笼统“准确率”；每个输出分别核实性能、用途与版本。

## 2. 验证设计

至少检查：

1. 训练、调参、内部验证、外部验证和前瞻性验证是否按受试者完全隔离。
2. 样本量指帧、片段、测量次数还是独立受试者；统计单位与置信区间是否正确。
3. 目标人群、疾病谱、设备、场景和操作者是否与部署一致。
4. 静息/运动、室内/室外、肤色、年龄、性别、BMI、合并症和药物等分层性能。
5. 金标准设备、同步方式、测量误差和参考方法是否适合目标用途。
6. 报告均值之外的误差分布、失败率、覆盖率、校准漂移和最差场景。
7. 最终 SDK/端侧版本是否就是被验证版本。

## 3. 捷径学习与混杂

模型可能从年龄、性别、BMI、设备、医院背景或拍摄环境推断总体均值，而非捕捉目标生理机制。

审计动作：

- 查看模型是否显式输入人口统计变量，或能从图像隐式恢复这些变量。
- 在年龄/BMI/医院/设备分层内报告增量性能，并与只用人口统计变量的基线比较。
- 做跨中心、跨设备、跨时间外部验证和混杂消融。
- 对低患病率筛查报告灵敏度、特异度、PPV、NPV 和 decision-curve；总体准确率可能被多数类主导。

显式使用人口统计变量不是自动造假，也不自动证明捷径学习；关键是模型在目标决策中是否提供可重复的独立增量。

## 4. 无袖带/摄像头血压

血压是高风险宣称。光学波形与压力之间通常依赖校准、波形形态、传播时间或统计映射，容易受混杂与分布漂移影响。

必问：

1. 是否需要每位用户袖带校准，校准多久失效？
2. 验证覆盖什么血压范围、姿势、运动、药物和患者群？
3. 与什么参考方法同步比较，采用哪个当期适用的标准/指南？
4. 许可编号及批文是否明确覆盖血压、输入形态和目标用途？
5. 同年龄/BMI 人群内、跨设备和跨中心性能如何？
6. 误差是否会改变高血压诊断或治疗决策？

腕带、接触式 PPG、多传感器和纯摄像头不是可互换先例。监管 clearance 证明特定用途获准上市，不等于所有场景下的测量准确性；仍需检查临床性能证据。无编号或仅新闻稿时标为未核实，不自动判定不存在。

## 5. 情绪与心理状态推断

先定义输出构念：面部动作、主观情绪、自我报告量表、临床诊断或风险筛查不是同一目标。

- 标注者一致性和量表信效度构成模型性能上限。
- 表情—情绪关系受文化、语境、个体和刻意控制影响。
- 若训练标签来自观察者猜测，模型更准确地复现标签不等于读取真实内在状态。
- 高风险用途需评估偏差、误伤、解释、人工复核、知情同意和可申诉机制。

报告必须说明模型实际预测的标签及其决策用途，不能把“表情分类”升级为“心理诊断”。

## 6. 数据壁垒

数据量只有在以下问题成立时才支持壁垒：

- 独立受试者数、重复测量结构和目标场景多样性清楚。
- 有高质量同步金标准与临床标签。
- 授权覆盖商业训练、迭代和目标用途，且可持续获得。
- 数据具有排他性或获取/标注成本难以复制。
- 数据增量能在独立目标任务上带来可重复提升。

“N 倍于公开数据”需给公开基数、纳排和去重；帧数不能冒充患者数。

## 7. 快速问题

1. 每个输出到底是直接测量、代理指标还是风险推断？
2. 最终产品版本在哪些独立人群和真实设备上验证？
3. 误差、失败率和覆盖率在最困难亚组怎样？
4. 金标准、同步、样本单位和置信区间是什么？
5. 人口统计基线能达到多少，模型提供多少独立增量？
6. 批文或拟申报用途是否覆盖材料中的全部声称？
7. 数据的权属、同意、排他性和持续获取机制是什么？
8. 平台集成或低价竞品出现后，客户付费理由是否由合同与续费验证？
