# 生命科学工具、CRO 与 CDMO：估值

## 1. 商业里程碑

```text
原型/方法 → 客户验证 → 首次付费 → 重复订单 → 标准化交付 → 复购/耗材拉动 → 规模化
```

## 2. 分部估值

- 仪器：装机、ASP、毛利、服务成本和更新周期；
- 耗材/试剂：装机基数、消耗率、复购、价格和流失；
- CRO/CDMO：backlog 转收入、利用率、项目组合和资本开支；
- 软件：ARR、留存、实施成本和独立销售能力。

按分部现金流估值，不给混合收入一个统一倍数。

## 3. 风险情景

加入客户项目取消、临床失败导致订单终止、设备利用率不足、扩产延期、质量事件、价格竞争和应收账款情景。Backlog 不是无风险收入，需按合同取消权和历史转化校准。
