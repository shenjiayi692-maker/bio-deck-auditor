# 生命科学工具、CRO 与 CDMO：技术和交付审计

## 目录

1. 业务分类
2. 技术证据
3. 质量与交付
4. 快速问题

## 1. 业务分类

区分仪器、耗材/试剂、软件、检测服务、CRO、CDMO 和渠道分销。收入、毛利、资本强度与复购驱动不同，必须分部分析。

## 2. 技术证据

- 仪器：精度、重复性、通量、故障率、维护和跨批一致性；
- 试剂：灵敏度、特异性、稳定性、批间差和保质期；
- 服务：方法验证、周转时间、失败/重做率和客户审计；
- 软件：集成、数据格式、复用性和客户实际使用。

对标客户当前流程和完整工作流成本，不只对标单项 benchmark。

## 3. 质量与交付

检查质量体系、资质适用范围、审计发现、产能、设备利用率、关键人员、供应商、样本链路和数据完整性。CRO/CDMO 的订单额需拆成 backlog、已启动、可取消、里程碑确认和实际回款。

## 4. 快速问题

1. 收入按仪器、耗材、软件和服务如何拆分?
2. 装机后的耗材复购和设备利用率?
3. Backlog 中可取消和未启动部分多少?
4. 客户审计、偏差、CAPA 和按时交付率?
5. 前五客户与单一项目集中度?
6. 扩产后单位经济和资本开支?
