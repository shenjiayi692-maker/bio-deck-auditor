# 消费健康与医疗美容：技术、合规与品牌审计

## 目录

1. 声称边界
2. 产品证据
3. 渠道与安全
4. 快速问题

## 1. 声称边界

逐渠道检查包装、广告、达人内容、销售话术和医生/机构话术。消费健康、化妆品、医疗器械、药品和医疗服务的边界由具体声称与使用方式决定，不能只看公司自称。

## 2. 产品证据

区分主观满意度、替代指标、短期外观变化和临床终点。检查对照、盲法、照片标准化、持久性、亚组、安全和不良事件。

## 3. 渠道与安全

- DTC、平台、经销、机构和医生渠道的毛利与获客成本；
- 复购是否来自真实效果、疗程需要或高促销；
- 退货、投诉、不良事件和召回；
- 医美机构资质、操作者培训和耗材真伪；
- 广告合规、KOL 依赖和平台政策风险。

## 4. 快速问题

1. 各渠道具体使用什么功效或疾病声称?
2. 效果证据的对照、持续时间和不良事件?
3. CAC、自然流量、复购和促销依赖?
4. 机构/经销商集中度与合规审计?
5. 退货、投诉和严重不良事件率?
6. 品牌、配方、器械和服务各自贡献多少毛利?
