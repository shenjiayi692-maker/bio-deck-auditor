# 创新药 / 生物制药:里程碑-概率表与估值参数

> 配合 `references/common/bridge-methodology.md` 使用。方法论讲"怎么算",本文件提供**这个赛道的阶段、概率、周期、成本**。
> 药物研发较多使用 rNPV，也有公开的分阶段转化率研究；但数据库、时间窗、治疗领域、阶段定义和样本选择差异很大，不能把行业均值当作项目事实。
> **坏消息**:中国特有的**医保国谈**是巨大的估值变量,美式模型里完全没有。见第4节。

## 1. 里程碑链

```
靶点发现 → 苗头化合物 → 先导优化 → 临床前 → IND → Phase I → Phase II → Phase III → NDA/BLA申报 → 批准上市
                                                                                                        ↓
                                                                      【中国】医保国谈 → 进院 → 放量
                                                                      【美国】支付方准入 → 处方 → 放量
```

**关键认知:批准上市不是终点。** 在中国,能否进医保、以多大降幅进,直接决定峰值销售。这一步的估值影响,常常比临床后期还大。

## 2. 里程碑-概率表(实证数据)

⚠️ **重要:成功率因治疗领域差异极大**(肿瘤远低于平均)。以下是行业平均,**具体项目必须按适应症调整**。

### 临床阶段转化率（仅作待核实先验）

| 阶段 | 转化到下一阶段的成功率 | 来源与说明 |
|---|---|---|
| 临床前 → IND | 部分行业模型约 69% | 模型假设值，不是监管数据库统计；需替换为项目口径 |
| **Phase I → II** | 历史研究常见约 40–60% | 按适应症、年份与“成功”定义替换 |
| **Phase II → III** | 历史研究常见约 25–40% | 常是重要淘汰关口，但不能据此判定单项目 |
| **Phase III → 申报** | 历史研究常见约 50–75% | 肿瘤等领域可能更低，需用同口径数据 |
| 申报 → 批准 | 历史研究常见约 80–95% | 仍受申报撤回、补充资料和口径影响 |

### 累积成功率（从 Phase I 算起）

不同研究对累计 LOA 的估计差异很大。报告中不要复制无完整引文的区间；从一项可访问的原始研究或数据库报告提取治疗领域、分子类型、样本期、起止阶段和删失规则，再用各阶段条件概率计算累计值，并至少做一组替代来源敏感性分析。

**审计用法**:Phase I 单管线的累计成功概率通常远低于单一阶段概率。应选取同治疗领域、同时间窗、同起止阶段的研究并展示敏感性分析。若 deck 直接按成功上市现金流估值，只能说明它遗漏了失败风险；在没有完整现金流和概率口径时，不输出“高估 N 倍”。

### 时间与成本

周期、受试者数和成本由适应症、试验设计、地区、招募速度、制造和失败成本口径决定。使用该项目 protocol、监管沟通、CRO 报价和可比试验实际进度建模；行业总成本研究只能作外部边界。

## 3. 中国特有:国谈与支付格局 ★

**这是美式rNPV模型完全缺失的一环,也是中国创新药估值的核心变量。**

### 国谈的价格变化（运行时用当期官方结果核实）

| 项目 | 数据 |
|---|---|
| 新增目录外药品 | 核实当年国家医保局公布的谈判成功率与平均价格变化 |
| 特定创新药类别 | 不用总体均值替代具体适应症、竞品和预算影响 |
| 续约 | 区分简易续约、重新谈判和竞价，不把一类结果外推全部品种 |

**估值含义(必须写进模型):**
1. **进医保通常伴随价格与可及性的联动。** 峰值销售不能只用国谈前价格 × 目标患者数；应按当年规则、竞品和预算影响设置多个价格/放量情景，不机械套固定折扣。
2. **不进医保的结果取决于替代支付。** 分析自费、惠民保、商业保险、慈善援助和院内准入，不预设价格或销量。
3. **续约按路径建模。** 简易续约、重新谈判和竞价的条件不同，用当期规则及同类品种结果设置情景。

**审计问题:deck 的峰值销售预测使用国谈前还是国谈后价格?** 若使用国谈前价格，应根据适应症、竞争、支付路径和当期谈判数据做情景调整，不能机械打固定折扣。

### 2025年的新变量:商保创新药目录

2025年国谈**首次增设商业健康险创新药品目录协商**,被视为新药支付体系的转折点。

- 意义:为医保之外打开支付空间,尤其对 **CAR-T、ADC、罕见病药**等高值创新药
- 价格与覆盖范围尚需按当期正式目录、保险产品和实际理赔核实；行业预测只能作候选假设。
- **审计动作**:高值创新药的deck,**必须问它走基本医保还是商保路径**。这直接决定了价格假设。⚠️ 此为新政策,运行时务必搜索最新进展

### 其他中国特有变量

- **集采暴露**:若管线包含仿制药、成熟品种或面临专利到期，按具体批次规则、竞价结果和适用范围评估，不跨品类套用平均降幅。
- **进院**:进了医保不等于进院。医保局已强调不得以总额限制、药占比等理由阻碍进院,但落地仍需时间

## 4. 估值方法选择

| 公司阶段 | 估值方法 | 折现率 |
|---|---|---|
| 临床前/发现期 | 实物期权法 / 可比交易 | 极高 |
| Phase I-II | **rNPV**(核心方法) | 高(生物科技级) |
| Phase III | rNPV,概率大幅提升 | 中高 |
| 已上市 | DCF / 可比公司 | 正常 |
| 有license-out交易 | **按交易对价反推**(见下) | — |

### License-out 估值法(中国biotech的重要变现路径)

对外授权交易的对价结构:
```
总额 = 首付款(upfront) + 各里程碑付款(milestone) + 销售分成(royalty)
```
⚠️ **审计陷阱:只宣传“总交易额”而不披露支付条件，会高估已实现价值。**
- 已确认现金通常主要是首付款及已达成付款；还要核实退款、成本分担和权利范围
- 或有里程碑付款按触发条件、时间和阶段概率调整
- **必查:首付款占总额的比例是多少?** 如果只有5%,那"XX亿美元交易"的风险调整现值可能只有零头
- **反向利用**:一笔真实的license-out交易,是**第三方对管线价值的定价**,比公司自己的PPT可信得多。用它做估值锚点

## 5. 本子领域特有的估值陷阱

**① 峰值销售的三重乐观**
deck的峰值销售 = 患者数 × 渗透率 × 价格。三个变量常常同时乐观:
- 患者数用流行病学总数(而非可及、确诊、符合适应症的)
- 渗透率假设过高(忽略竞品)
- 价格用国谈前(见第3节)
多个乐观假设会相乘放大。逐项做敏感性，不预设每项固定高估倍数。

**② 忽略竞争格局**:同靶点有多少家在做?中国的"内卷靶点"(PD-1等)会导致上市即价格战。**必查:同靶点/同适应症的国内在研数量。**

**③ 单管线 vs 管线组合**:单管线公司的风险是二元的(成/败)。多管线可分散,但也稀释资源。**审计:哪条是核心管线?其他是不是凑数的?**

**④ 适应症拓展的"免费期权"**:deck常把未来的适应症拓展算进估值。这些**必须单独打概率**,不能免费计入。

**⑤ 数据的"选择性披露"**:先检查预设主要终点、统计分析计划和多重性，再看关键次要终点、亚组、安全性和总证据；不能用探索性亚组替代主要结论，也不能忽略有临床意义的安全性结果。

**⑥ 临床试验的可核实性**:所有声称的临床试验,应在 ClinicalTrials.gov 或中国临床试验注册中心可查。**查注册号、查主要终点、查状态。** 这是最硬的外部核实。

## 6. AI制药(TechBio)专节 ★

**这是本子领域与"生物+AI"交叉最深的部分,也是估值套利最严重的地方。**

### 核心问题:它是药企还是平台?

见 `references/common/cross-domain.md` 的"伪装型"结构。这里给出药领域的具体判定:

| 检验 | 若为"真平台" | 若为"实为药企" |
|---|---|---|
| 有无第三方付费客户 | 有多个非关联药企付费使用 | 平台只服务自己的管线 |
| 收入形态 | 订阅/服务费,可复现 | 里程碑付款/license-out(=药企收入) |
| 若自有管线全灭 | 平台仍有客户 | 平台证据显著减弱；是否仍有价值取决于第三方客户和独立验证 |
| 平台的验证 | 已有客户用它做出东西 | **只有"我们自己在用"** |

**判定后果(这是估值上最贵的一个判断):**
- **平台只服务自有管线** → 先按管线 rNPV；平台对速度、成本或成功概率的增量只在有可比证据时单列
- **真平台** → 拆成 平台(SaaS估值) + 自有管线(rNPV),按**组合型**相加
- **平台无客户、管线尚早** → 用早期期权或里程碑融资法，区间由现金、团队、IP、可比交易和下一里程碑决定

### AI制药特有的技术审计

**必问:AI到底加速了哪一步?量化证据是什么?**

AI制药的价值主张通常是"更快/更省/成功率更高"。**审计时逼它量化:**
1. **加速了哪个环节?** 靶点发现?分子设计?临床试验设计?——**不同环节的价值天差地别**
2. **有对照吗?** "我们18个月做出了传统需要4年的分子"——**和什么比?** 有没有同期的传统方法对照?
3. **最关键的检验:AI设计的分子,临床成功率更高吗?**
   - **这是整个AI制药命题的核心,而目前公开证据仍然稀薄**
   - AI能加速**临床前**(设计、筛选),但**临床失败主要发生在Phase II(疗效)**——而Phase II失败的根源是**生物学/靶点选错**,不是分子设计不够好
   - **即:AI优化了不是瓶颈的那一环。** 除非公司能证明它的AI提升了**靶点选择**的质量,否则它对最关键的成功率没有改善
   - ⚠️ 这是一个强质疑,但也要公平:该领域在快速演进,**运行时应搜索最新的AI设计药物的临床结果数据**,不要用陈旧的立场下判断

**判定**:如果 AI 只作用于临床前且没有与历史/同期对照可比的临床证据，不因“使用 AI”自动上调成功概率。基准概率仍需选择与适应症、阶段、分子类型和时期匹配的外部数据，并做敏感性分析。
