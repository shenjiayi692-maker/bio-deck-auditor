## 1. 科学风险的分层:靶点 > 分子 ★

**这是本领域最重要的一个认知,它决定了你该把审计火力放在哪里。**

药物开发的失败,按根因排序:

```
靶点选错(生物学假设错误)  ← 最主要的失败原因,发生在 Phase II
      ↓
分子不够好(成药性、毒性)   ← 次要,发生在 Phase I / 临床前
      ↓
临床试验设计/执行问题       ← 可修复
```

**关键推论：**
- Phase II 常是重要淘汰阶段，但转化率与失败原因随治疗领域、分子类型和时期变化；使用匹配数据，不固定套一个区间。
- 更好的分子未必能弥补错误的疾病生物学假设，但暴露、选择性、毒性、剂量和试验设计也可能导致疗效失败，需逐项目归因。

**审计动作:把火力集中在靶点验证上,而不是分子的漂亮程度。**

**靶点验证的证据等级(从弱到强):**
| 等级 | 证据 |
|---|---|
| 最弱 | 细胞实验、体外数据 |
| 弱 | 动物模型(**动物模型的转化失败率极高**) |
| 中 | 人类遗传学证据(该靶点的天然突变人群表型) ← **含金量高** |
| 强 | 同靶点的其他药物已在人体验证过机制 |
| 最强 | 同靶点已有药物获批 |

**问:这个靶点有人类证据吗?** 只有动物数据的新靶点,Phase II 风险极高。
**反之**:一个"me-too/me-better"药物(靶点已验证)的科学风险低得多——但商业风险(内卷)高得多。**这个权衡要在报告里说清楚。**

## 2. 临床前数据的可信度审计

**默认立场:临床前数据的预测力很弱。** 大量在动物身上有效的药物在人身上失败。

**审计要点:**
- **动物模型的相关性**:这个模型真的模拟了人类疾病吗?(很多模型是人为诱导的,和真实疾病机制不同)
- **可重复性**:临床前研究的可重复性危机是公开的问题。数据是独立实验室复现过的吗?
- **效应量 vs 显著性**:p<0.05 不等于有临床意义。**效应量有多大?**
- **样本量**:动物实验常常n很小
- **选择性报告**:做了多少个实验,报告了几个?

**不要被漂亮的临床前数据说服。** 它是必要条件,远非充分条件。

## 3. 临床数据的解读陷阱

**必查清单:**

**① 主要终点(primary endpoint)达到了吗?**
这是首要锚点，但还要同时看安全性、关键次要终点、统计分析计划和临床意义。常见话术：
- "次要终点显著改善" → **主要终点失败了**
- "在亚组中显示出疗效" → **总体失败了,亚组分析是事后挑的**
- "显示出积极趋势" → **没有统计学显著性**

**② 对照组是什么?**
- 安慰剂对照 vs **标准治疗(SOC)对照**——后者才有商业意义。打赢安慰剂但打不赢现有药物,没人会买
- 单臂试验(无对照)的证据等级低得多

**③ 终点的临床意义**
- **替代终点 vs 硬终点**:肿瘤缩小(替代)≠ 活得更久(硬终点,OS)。很多药改善了ORR/PFS但不改善OS
- 问:这个终点被监管机构接受吗?

**④ 样本量与统计功效**:早期小样本的惊艳结果,在大样本中经常消失

**⑤ 试验的可核实性**:
**所有临床试验应在 ClinicalTrials.gov / 中国临床试验注册中心可查。**
- 查注册号
- **对比:注册时的主要终点 = 论文/deck里报告的主要终点吗?**(终点被中途改掉是重大红旗)
- 查试验状态(在招募?已完成?**终止了?**)

## 4. AI制药的技术审计 ★

**核心质疑:AI优化的,是不是瓶颈那一环?**

见 `references/domains/drug/milestones-valuation.md` 第6节的估值判定。这里给技术审计的方法:

**AI在药物开发中的位置:**
```
靶点发现 → 分子设计 → 临床前 → Phase I → Phase II(最大死亡谷) → Phase III
    ↑           ↑                              ↑
  AI较少介入   AI主战场                    失败主要发生在这里
                (设计、筛选、优化)
```

**推论**:如果AI只作用于"分子设计"环节,它加速了研发**速度**,但**未必提升最终成功率**——因为失败的主因(靶点错误)不在它优化的环节。

**必问的三个问题:**
1. **你们的AI作用于哪一环?** 靶点发现?分子设计?临床试验优化?
2. **如果只是分子设计**：它解决了哪个可量化瓶颈（周期、命中率、性质、实验轮次或成本）？为什么可能影响后续成功概率？
3. **如果声称能改进靶点选择**:证据是什么?(这才是真正有价值的宣称,但也最难证明)

**公平性提醒**:该领域在快速演进,已有AI设计的分子进入临床。**运行时应搜索最新的临床结果数据**,不要用陈旧立场下判断。但**举证责任在公司**——它必须证明成功率提升,而不是假设。

### AI 药研证据阶梯

把“模型领先”沿价值链逐级核实，前一级不能替代后一级：

1. **离线 benchmark**：数据划分、时间切分、结构/序列相似性泄漏、基线、重复运行和置信区间。
2. **计算候选质量**：有效性、唯一性、可合成性、性质约束、对接/结构指标；明确“成功率”的分母与判定器。
3. **湿实验**：合成成功、活性、选择性、表达、稳定性、毒性；盲法、批次、失败样本和独立复现。
4. **设计—制造—测试—学习闭环**：每轮候选数、命中率、周期、成本和相对人工/历史基线的增量。
5. **项目资产**：候选确认、IND-enabling、IND、临床或 license-out；区分平台贡献与团队/合作方贡献。
6. **客户价值**：付费项目、交付验收、复购、节约的时间/实验/成本和客户可披露案例。

### 智能体与对话式平台

- 用真实研发任务评测端到端完成率、引用正确率、工具调用成功率、事实错误率、专家修改时间和失败恢复，不只测问答榜单。
- 检查检索语料的日期、版权/许可、实体消歧、版本和可追溯性；“能引用”不等于引用支持结论。
- 区分 Copilot（专家审批）与 Autopilot（自主执行）的责任边界、审批点、审计日志和生物安全控制。
- 比较通用模型 + 开源工具链的替代方案；壁垒可能在私有数据、工作流集成、湿实验反馈、客户验证和转换成本，而非参数量。
- 计算训练/推理、数据库许可、人工专家和项目交付成本，验证毛利随客户规模是否改善。

**其他 AI 制药技术审计：**
- **数据从哪来?** 药物数据的稀缺性和专有性。用公开数据训练的模型,壁垒在哪?
- **"我们18个月做出了传统需要4年的分子"** → 和什么比?有对照吗?**速度快但质量如何,要等临床结果**
- **湿实验闭环**:纯计算的公司 vs 有自己湿实验室的公司。前者的模型缺乏真实反馈
- **验证的循环论证**:用AI预测的分子,再用另一个AI模型验证——这是自证,不是验证
- **指标命名**：“单次生成成功率”“SOTA”“Top 1”必须给任务、数据集、分母、阈值、基线、测试代码和是否由自有模型充当判定器。
- **开放与闭源边界**：开源模型验证技术能力，也降低客户替代成本；核实闭源增量、许可证、权重可得性和商业化权利。

## 5. 竞争格局:内卷靶点 ★

**中国创新药的最大商业风险之一。**

在中国,一个被验证的热门靶点会迅速涌入大量玩家(PD-1是经典案例)。后果:
- 上市即价格战
- 国谈时因非独家而降幅更大(**非独家药品面临"生死竞价"**)
- 峰值销售被摊薄

**审计动作(必做):**
1. **查同靶点/同适应症的国内在研数量**(可在药物研发数据库查)
2. **排名与时间差**：这家公司在同靶点/同适应症的临床与注册顺序、数据成熟度和预计上市时间如何？不能用固定名次直接归零。
3. **差异化**:如果不是first-in-class,那它的 best-in-class 依据是什么?(更好的疗效?更少副作用?更方便的给药?)——**要有头对头数据,不是嘴上说说**

**判定**:一个在拥挤靶点里排名靠后的管线,**即使临床成功也可能没有商业价值**。技术成功 ≠ 商业成功,这在药领域尤其残酷。

## 6. 快速问题清单

**靶点与科学**
1. 这个靶点有**人类证据**吗?(遗传学证据/已获批药物)还是只有动物数据?
2. 如果是新靶点,Phase II 的生物学假设是什么?怎么验证?
3. 如果是已验证靶点,同靶点国内有多少家在做?你们排第几?

**临床数据**
4. 主要终点(primary endpoint)是什么?达到了吗?
5. 对照组是安慰剂还是标准治疗?
6. 终点是替代终点还是硬终点(OS)?监管接受吗?
7. 试验注册号是什么?(核实:注册时的终点 = 报告的终点?)

**AI制药(若适用)**
8. 你们的AI作用于哪一环?如果是分子设计,凭什么认为最终成功率会提升?
9. 平台有第三方付费客户吗?如果自有管线全灭,平台还值多少钱?
10. AI设计的分子,已进入临床的有几个?到哪个阶段了?结果如何?

**商业与估值**
11. 峰值销售预测用的是**国谈前还是国谈后**的价格?
12. 你们走基本医保还是商保创新药目录?
13. (若有license-out)首付款占总交易额的比例是多少?
14. 现金能烧到哪个里程碑?下一轮融资的触发条件是什么?
