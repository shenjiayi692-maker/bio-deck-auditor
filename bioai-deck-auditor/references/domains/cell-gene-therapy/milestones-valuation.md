# 细胞与基因治疗：里程碑与估值

## 1. 里程碑链

```text
概念/靶点 → 工艺与分析方法 → 临床前 → IND → 早期安全/信号 → 确证试验 → 申报 → 生产与支付 → 放量
```

逐阶段同时跟踪临床与 CMC。临床信号领先而工艺未锁定时，阶段不能只按临床进度上调。

## 2. 估值方法

- 临床前/临床期治疗产品：按适应症和产品做 rNPV 或情景模型。
- 平台：只有存在独立第三方付费、可重复交付或多项目外部验证时单独计价。
- CDMO/工具收入：与治疗管线分部估值，不共享同一成功概率。

模型加入制造失败、产能资本开支、长期随访、患者识别、治疗中心扩张、一次性疗法支付和潜在安全事件情景。

## 3. 特有陷阱

- 用极少数响应者外推全部患者；
- 忽略制造失败和不可治疗患者；
- 把学术中心工艺当作可规模化商业工艺；
- 把平台所有未来适应症免费计入估值；
- 只看疗效，不建长期安全和支付情景。

所有阶段概率和成本按适应症、技术类型、辖区和当前数据核实，不套用统一 CGT 平均值。
