# 脑机接口（BCI）：里程碑与估值

> 配合 `references/common/bridge-methodology.md` 使用。BCI 的产品形态和预期用途差异很大，不能把“侵入/非侵入”直接映射为固定类别、周期或估值倍数。所有先例、价格和竞品状态运行时查一手来源。

## 1. 先拆产品边界

至少区分：植入/半植入系统、非侵入采集设备、解码软件、闭环刺激/康复系统、辅助诊断软件和科研工具。逐项记录预期用途、目标患者、输出、与其他设备的组合关系、申报主体和目标市场。

| 维度 | 植入/半植入 | 非侵入/外置 |
|---|---|---|
| 主要风险 | 手术、长期植入安全、可靠性、伦理、取出/维护 | 信号质量、佩戴与校准、外部验证、依从性、工作流 |
| 证据重点 | 长期安全、器械故障、临床功能终点、手术可实施性 | 在线闭环表现、患者有效率、对照康复增量、跨中心泛化 |
| 商业重点 | 中心能力、手术与随访成本、支付、长期服务 | 设备利用率、治疗师时间、耗材、采购与服务合同 |

风险通常不同，但壁垒高低必须由具体证据决定；非侵入产品也可能通过临床证据、工作流、数据权利或渠道形成壁垒。

## 2. 里程碑链

### 非侵入医疗用途

原理/样机 → 在线患者验证 → 产品定型与型检 → 临床评价/试验 → 注册 → 支付或采购路径 → 进院 → 重复使用与回款

### 植入或半植入用途

设计与风险分析 → 台架/可靠性/生物相容性 → 动物或其他临床前证据 → 伦理与临床试验 → 注册 → 手术中心培训 → 长期随访与商业化

每个里程碑记录证据文件、剩余时间、成本、条件概率和相互依赖。BCI 缺少可直接套用的公开分阶段成功率时，使用情景分析，不制造精确单点概率。

## 3. 监管先例怎么用

对“首个、唯一、已获批、进入创新通道”等宣称：

1. 在目标监管机构数据库按公司名、产品名和注册/受理号核实。
2. 比较产品形态、预期用途、适用患者、侵入程度、输出与获批范围。
3. 把新闻稿或媒体报道当候选线索；“全球首个”还需定义检索范围并跨辖区核实。
4. 先例只降低相似路径的不确定性，不自动证明被审产品可获批、疗效相同或具有排他壁垒。

## 4. 临床与支付桥接

- 分开方向性文献、公司自己的随机试验、单臂研究、真实世界使用和病例展示。
- 康复产品评估相对常规康复的增量、临床重要差异、持续时间、训练剂量和治疗师投入。
- 医疗服务价格是医院可收费项目的线索，不是设备/软件企业收入。企业收入需由采购、租赁、订阅、耗材或分成合同支持。
- 省级价格、医保支付、患者自付和医院成本分别建模；不把单一地区价格外推全国。

## 5. 估值层级

| 情形 | 建议方法 |
|---|---|
| 植入/高风险、临床前或临床期 | 数据足够时用 rNPV；否则做里程碑情景 |
| 非侵入、拿证前 | 里程碑情景或隐含假设分析 |
| 已拿证但未形成重复采购 | 订单 cohort、单位经济和进院转化情景 |
| 已规模化 | DCF/可比，分拆设备、耗材、软件与服务 |

牌照“首发”是否有溢价，取决于后续竞品进入速度、适用范围、临床差异、支付和客户切换成本。不要预设首证有永久溢价，也不要预设没有价值。

## 6. 创始人问题

1. 注册或拟申报的预期用途原文、分类依据和产品边界是什么？
2. 当前版本完成了哪些台架、在线、患者、跨中心和长期验证？
3. 主要临床终点、对照、样本量、退出率和不良事件是什么？
4. 低响应人群、校准时间和跨天稳定性如何？
5. 现有医院是科研、临床试验、试用、采购还是重复付费？
6. 医院服务收费、设备采购、软件费、耗材与企业分成分别是多少？
7. 关键 IP、数据和医院合作权利属于谁，是否排他？
8. 本轮资金能覆盖到哪个降低风险的里程碑，预算和时间缓冲是多少？
