## 1. 技术分层:一个完整BCI系统的四个环节

BCI 系统通常可拆成中枢神经信号采集、信号处理/解码、外部执行和反馈等环节；具体产品是否属于医疗器械、产品边界如何界定，应以预期用途、申报单元和当期正式分类界定为准，不能用一条概念定义代替监管判断。

```
信号采集(EEG/植入电极) → 特征提取 → 解码/意图识别 → 外部执行(FES/外骨骼/轮椅) → 反馈回大脑(闭环)
```

**审计动作:公司的产品覆盖了哪几环?**
- **只做信号采集(脑电放大器/采集帽)** → 可能是独立器械、系统部件或科研设备，取决于预期用途与申报方式；其价值还受硬件性能、舒适性、供应链、渠道和数据质量影响，不能只按“是否完整 BCI”判断。
- **解码算法**:常是重要审计对象，但壁垒也可能在电极、植入工艺、闭环方案、临床工作流或量产质量体系。
- **闭环(如MI-BCI-FES)**:把解码结果转成电刺激/外骨骼动作再反馈——这是卒中康复的主流范式,方向有临床共识支持

## 2. "解码准确率"的陷阱

BCI最爱报的指标是"运动想象识别准确率≥85%"之类。**这个数字有多个陷阱:**

**① 几分类?** "左右手二分类85%"和"多指精细控制85%"难度差一个数量级。**二分类的85%其实不高**(随机是50%,好的系统可达90%+)。追问:几分类?混淆矩阵?

**② 离线 vs 在线?** 离线(事后分析录好的数据)准确率 >> 在线(实时闭环)。**临床有意义的是在线实时性能。**

**③ 健康人 vs 患者?** 卒中患者的EEG信号因脑损伤而异常,**在健康人/学生身上的解码率,不代表在患者身上的**。而患者才是市场。

**④ 跨受试者/跨天?** BCI有严重的**个体差异和跨天漂移**——同一个人今天的模型明天可能失效。这是"自适应迁移算法"想解决的真问题。追问:需要每次重新校准吗?校准要多久?

**⑤ 低响应/难控制人群**:文献曾报告一部分受试者难以达到稳定控制，但比例会随范式、阈值、训练和人群而变，且“脑机盲”标签本身存在争议。追问应覆盖有效率、退出率、训练时间和失败者特征，而不是预设固定比例或永久无效。

## 3. 数据壁垒:BCI版

BCI公司常宣称"私有数据是全球公开数据的N倍"。按 `references/common/audit-tech-common.md` 的数据壁垒四条检验,BCI特有的点:

- **EEG数据的价值在于配对的临床标签**:光有脑电波不够,要有配对的康复结局(FMA评分改善等)。**有标签的数据才是资产。**
- **排他性**:数据来自合作医院,是排他协议吗?其他公司能否从同样的医院拿到?
- **"N倍于公开数据"要核实基数**:公开BCI数据集本身就小,N倍可能绝对量仍有限。且**数据多样性**(病种、病程、电极配置)比总量重要
- **合规**:EEG是敏感个人信息 + 医院数据商用训练需伦理审查+知情同意范围

## 4. 临床证据的分级(本赛道最关键的审计)★

BCI康复是**方向已被认可、但证据强度参差**的领域。必须精确分级:

| 证据等级 | 形态 | 可信度 |
|---|---|---|
| **最强** | 权威指南/专家共识的强推荐 + 大样本多中心RCT | 高 |
| 强 | 自己的RCT(有对照、随机、预设主要终点) | 较高 |
| 中 | Meta分析支持方向(但纳入研究样本小、异质性高) | **该赛道现状:low-to-moderate** |
| 弱 | 单臂/回顾性研究 | 低 |
| **最弱** | **个案/病例展示("某患者N天见效")** | **轶事,非疗效证据** |

**赛道证据状态须运行时复核：**卒中运动康复已有随机研究、综述和共识，但效应大小、偏倚风险、异质性和长期功能结局会随纳入研究而不同。意识障碍、言语、认知等适应方向应分别评价，不能从运动康复外推。报告必须列出使用的综述/指南版本、检索日期和具体证据等级。

**审计动作:**
1. 公司引用的是哪一级证据?**把"个案见效"和"RCT证据"严格分开**
2. **专家共识背书要查利益关联**:通讯/执笔作者里有没有创始人本人?(BCI领域专家圈子小,自我背书常见,需披露)
3. **和同行的RCT规模对标**:"我们N例最大样本"——是RCT还是累积?对方的RCT多少例?
4. 康复效果的"提升X%",对照组是什么?常规康复本身也有效,**增量在哪?**

## 5. 神经科学叙事的边界

BCI天然带神经科学光环,容易出现叙事跳跃(见 `references/common/audit-tech-common.md` 叙事跳跃检测):

**常见的过度宣称:**
- **"重塑神经环路""神经可塑性"**:MI-BCI-FES促进可塑性有机制假说和一定证据,但"重塑"的程度、持久性、对硬终点(长期独立生活能力)的影响,证据有限。**别把机制假说当已证疗效。**
- **"解码大脑意图"→"认知目标解码"→"读取深层意图"**:从解码运动想象(相对成熟)到"认知/深层意图解码"是一个**巨大的技术跳跃**,目前科学上远未成熟。deck若把后者当作近期能力,是跳跃
- **"全病种平台"**:一个MI康复算法,不会因为叫"平台"就能迁移到意识障碍、言语、认知等完全不同的任务。**追问跨任务的实证。**
- **通用EEG基座模型**:同 bioai-sensing 的基座模型审计——要求证明可迁移性、scaling、第三方使用

## 6. 快速问题清单

**技术**
1. 产品覆盖BCI四环节的哪几个?只做采集还是含解码+闭环?
2. "准确率85%"是几分类?在线还是离线?健康人还是患者?跨天稳定吗?
3. 需要每次重新校准吗?低响应或难控制人群的比例、退出率与有效率是多少?
4. "自适应迁移算法"具体解决了跨受试者/跨天漂移到什么程度?有对比数据吗?

**数据**
5. 私有数据有配对的临床结局标签吗?多少例有标签?
6. 数据协议排他吗?其他公司能否从同样医院获取?

**临床证据**
7. 你们的核心证据是RCT、Meta支持的方向、还是病例展示?
8. "N例最大样本"是RCT吗?有对照和主要终点吗?vs 同行的RCT规模?
9. 引用的专家共识,执笔人里有创始人吗?
10. "康复提升X%"的对照组是什么?相比常规康复的增量?

**监管/竞争**
11. 侵入还是非侵入?二类还是三类?
12. 非侵入康复赛道已有思易(二类)、念通(冲三类)等——你的监管进度对标他们如何?
13. 下一步管线几款走三类?4000万够几个三类RCT?

**商业**
14. "N家医院N例"里,付费采购vs科研合作各占多少?回款账期?
15. 医院适配服务价格、设备采购价、软件费和企业分成分别是多少?单台设备利用率与医院回收期如何?
16. 论文/影响因子是公司资产还是创始人实验室的历史积累?
