# 动态事实来源清单

## 使用方法

这些链接是核实入口，不是永不过期的答案。运行时打开一手来源，记录访问日期，并检查是否有更新、废止或适用范围变化。

| 主题 | 一手来源 | 快照/状态 | 使用限制 |
|---|---|---|---|
| NMPA AI 医用软件分类界定 | https://www.nmpa.gov.cn/ylqx/ylqxggtg/20210707111147171.html | 2021 指导原则 | 需结合当前分类目录和具体预期用途 |
| 医疗器械分类规则 | https://english.nmpa.gov.cn/2019-10/11/c_415411.htm | 规则入口 | 中文正式文本优先 |
| AI 医疗器械注册审查 | https://www.cmde.org.cn/ | CMDE 指导原则入口 | 搜索当前版本及修订状态 |
| FDA 510(k) 数据库 | https://www.accessdata.fda.gov/scripts/cdrh/cfdocs/cfpmn/pmn.cfm | 动态数据库 | 核对适应范围，不把 clearance 等同完整临床有效性 |
| ClinicalTrials.gov API | https://clinicaltrials.gov/data-api/api | v2 | 关键词结果仅为候选；需字段匹配 |
| 中国临床试验注册中心 | https://www.chictr.org.cn/ | 动态登记库 | 反爬和检索限制可能导致漏检 |
| 国家医保局神经系统价格立项指南 | https://www.nhsa.gov.cn/art/2025/4/27/art_201_16376.html | 2025 | 价格项目不等于企业收入或自动医保报销 |
| 湖北 BCI 医疗服务价格案例 | https://www.nhsa.gov.cn/art/2025/12/5/art_14_18951.html | 2025 | 地区价格；收入归属需看企业合同 |
| FDA 无袖带血压临床性能草案 | https://www.fda.gov/regulatory-information/search-fda-guidance-documents/cuffless-non-invasive-blood-pressure-measuring-devices-clinical-performance-testing-and-evaluation | 2026 草案 | 草案非最终实施文件 |
| WIPO 生物医药 rNPV | https://www.wipo.int/web-publications/intellectual-property-valuation-in-biotechnology-and-pharmaceuticals/en/3-the-income-approach.html | 方法参考 | 根据项目数据和风险口径调整 |

第三方市场数据库、商业媒体和企业新闻稿可以提供线索，但必须与独立来源交叉验证，且不能替代正式批文、登记记录或合同。
