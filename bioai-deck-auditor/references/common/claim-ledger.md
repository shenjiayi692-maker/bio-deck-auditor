# 宣称台账与材料摄取

1. 摄取顺序

## 1. 摄取顺序

1. 记录文件名、材料日期、版本、审计时点、页数和语言。
2. 提取文本层、备注、图表值和媒体清单；对图片型页面渲染并 OCR。
3. 检查图表、页脚、附录、Logo 墙、截图、二维码、视频封面和隐藏/备注内容。
4. 为每条宣称保留页码和原文，不先改写成结论。
5. 对跨页重复宣称保留多个来源页，随后核对口径一致性。

若某页无法可靠读取，记录页码、原因和缺失范围。不要默默跳过。

## 2. 原子宣称规则

一条宣称只表达一个可验证命题。例如：

- “已与四家三甲医院合作并实现回款”应拆成合作医院数量、医院等级、合同状态和回款状态四条。
- “准确率 95%”至少拆出指标、数据集、样本量、人群、金标准和验证方式；材料未给出的字段保持未知。
- “拥有 12 项专利”拆出专利类型、申请/授权状态、申请人和同族去重。

宣称类型至少覆盖：技术性能、临床证据、监管、商业牵引、财务、市场、IP、团队、路线图、第三方背书和估值。

## 3. 台账字段

机器可读格式见 `references/schemas/claim.schema.json`。核心字段：

| 字段 | 含义 |
|---|---|
| `claim_id` | 稳定编号，如 C-001 |
| `slide` | 页码或页码数组 |
| `verbatim` | 材料原文 |
| `normalized_claim` | 不增加事实的标准化表述 |
| `claim_type` | 宣称类型 |
| `entity` | 宣称归属的法律实体 |
| `product` | 所属产品/管线 |
| `product_version` | 型号、软件版本或注册单元 |
| `temporality` | 历史事实、当前状态、预测/计划或未知 |
| `jurisdiction` | 目标司法辖区 |
| `period` / `unit` | 时间口径与单位 |
| `deck_evidence` | 表格、图表、正文、截图或 Logo 墙 |
| `verification_status` | 未核实、候选、已核实、矛盾、无法核实 |
| `external_sources` | 来源、访问日期和匹配字段 |
| `evidence_grade` | A–E，见 evidence-calibration |
| `impact` | 若错误对投资逻辑的影响 |
| `confidence` | 当前判断置信度 |
| `counterevidence` | 已知反证或替代解释 |
| `next_action` | 下一步核实动作 |

## 4. 图表与 OCR

- 图表数字同时记录轴、单位、期间和是否为累计值。
- Logo 只证明材料展示了该名称，不证明客户、合同或收入。
- 截图记录可见账号、时间、环境和是否可能为测试数据。
- OCR 置信度低或关键数字模糊时，标记 `ocr_confidence: low`，不得用于致命红旗。
- 页码引用使用材料实际页码；若 PDF 页序与印刷页码不同，同时记录两者。

## 5. 完成检查

在进入分析前确认：

- 每页已读或明确标记不可读；
- 所有关键数字有页码和单位；
- 每个产品、管线和目标市场已分开；
- 宣称台账没有混入外部事实或分析判断；
- 跨页冲突已列为待核对差异。
