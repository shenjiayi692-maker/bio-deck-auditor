# 团队与治理审计

团队页不是履历摘要，而是对“谁能完成哪个里程碑、权利是否属于公司、资金是否够用”的核查入口。

## 1. 人员与投入

- 将创始人、科学顾问、临床 PI、董事和全职员工分开，不能把顾问或合作方算作执行团队。
- 核实关键人员的当前任职、投入比例、竞业/利益冲突和实际职责；历史任职与论文署名不等于当前全职投入。
- 把未来 18–24 个月里程碑映射到岗位：研发、临床、注册、质量、生产、销售和财务是否有明确负责人。
- 对关键人依赖给出替代方案和招聘周期，不因“名校/大厂背景”自动推定执行能力。

## 2. 履历与背书

- 学位、任职、论文、专利、临床试验和产品获批逐项按实体与时间核实。
- 区分“参与团队”“项目负责人”“第一/通讯作者”“专利发明人”和“成果权利人”。
- 顾问、医院和高校 logo 只证明材料中的关联宣称；合同、授权范围和持续性才决定可依赖程度。
- 发现不一致时先排除同名、组织更名、时间口径和兼职关系，再判断严重度。

## 3. IP 与成果转化

- 核查专利申请人/权利人、职务发明、软件著作权、代码与数据权属、医院/高校许可、地域和用途限制。
- 关键成果若产生于创始人前雇主或高校，要求提供转让/许可、利益冲突审批和后续改进成果归属。
- 独占许可需检查期限、最低付款、里程碑、再许可、终止和控制权变更条款。
- “有专利”不等于自由实施（FTO）或有效壁垒；另看权利要求覆盖、剩余期限和绕开难度。

## 4. 股权、交易与治理

- 核查 cap table、期权池、历史融资、可转债/SAFE、优先权、对赌、清算优先和潜在稀释。
- 识别关联方客户、供应商、研究机构、渠道和资金往来；关联交易收入不能直接当市场验证。
- 检查董事会席位、重大事项否决权、关键人保险、合规责任和举报/数据事件处理机制。
- 对客户、收入、试验和论文同时与创始人/股东关联的情形，降低独立验证权重但不自动判为虚假。

## 5. 融资跑道与里程碑

建立按月资金桥：期初现金 + 本轮净融资 + 可确认收入 − 人员 − 临床/注册 − 生产 − 销售 − 管理 − 偿债。

- 融资金额要覆盖到下一个能实质降低风险的里程碑，并留出审批、招募和回款延迟缓冲。
- 区分已签约融资、意向额度、政府补助申请和可提款授信。
- 里程碑预算需与受试者数、中心数、生产批次、注册路径和招聘计划互相一致。
- 资金不足是融资风险；只有当它使既定里程碑在时间和成本上不可行时，才升级为执行红旗。

## 输出要求

每个团队治理问题写明：材料宣称、核实状态、对执行或权属的影响、可消除疑虑的文件。优先索取劳动/顾问协议、cap table、知识产权清单与许可、关联方清单、月度预算和董事会批准材料。
