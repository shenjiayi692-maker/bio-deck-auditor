## 1. 收入的质量(不是数量)

**核心原则:deck会给你一个大数字。你的工作是把它拆成"这钱到底是什么"。**

### 收入质量金字塔(从最假到最真)

```
LOI / MOU / 战略合作协议     ← 几乎无价值,但deck最爱展示
框架协议 / 意向订单
POC / 试点合同(可撤销)     ← 医疗AI最常见的"收入"
已签合同(未回款)
已回款
可复制的、重复的规模化订单   ← 只有这个才支撑估值
```

**审计动作:把deck里的每一笔"收入"归到这个金字塔的某一层。** 通常会发现,声称的"XXX万订单"里,绝大部分在下三层。

### 必查项

1. **加总核对**:客户明细表加起来,等于封面写的总额吗?(**对不上是极常见的**)
2. **回款率**:签了多少,收到多少?
3. **POC转化率**:多少试点转成了规模采购?(见合规层4.3的Pilot Purgatory)
4. **客户集中度**:前3大客户占多少?结合公司阶段、合同期限、客户质量、续约和替代成本判断。早期高集中度常见，不能只按阈值定级
5. **关联方交易**:客户里有没有股东、投资人、创始人的关系方?(这类收入不算数)
6. **一次性 vs 经常性**:NRE(定制开发费)、设备一次性销售,都是一次性的。它们**不能按SaaS的倍数估值**
7. **收入的合规性**:这些收入本身合法吗?(见合规层——无证卖医疗设备的收入,是负债不是资产)

### 增长曲线的现实性检验

**方法:从"已知的今天"倒推"承诺的明天"需要发生什么。**

> **实例**:一家公司已签合同 241万,预测本年度收入 2151万。现在已过半年。
> → 意味着下半年要新签 1900万+。
> → 但目前最大的单笔合同是 104万。
> → **需要同时拿下18个史上最大订单,或者一个从未出现过的量级的大单。**
> → 问:**这个大单是谁?在哪一步?** 如果答不出具体名字和阶段,这条曲线就是画的。

**这个倒推动作对任何deck都适用,而且几乎总能问出东西。**

## 2. 单位经济与毛利率的真相

### 毛利率是业务实质的线索，不是测谎仪

下表只用于触发追问，不能直接给公司定性。会计科目、云推理、数据采购、渠道、客户成功、实施和收入结构都会影响毛利率。

| 毛利率 | 暗示的真实业务 |
|---|---|
| 80-90%+ | 可能接近高毛利软件；检查是否漏计云、支持和实施成本 |
| 60-70% | 可能含渠道、云推理、数据、硬件或实施 |
| 40-60% | 强烈提示项目制、硬件或高交付成本，需拆分验证 |
| <40% | 常见于制造、渠道或重交付业务，也可能处于早期爬坡 |

**审计动作**:把deck声称的毛利率,和它自称的品类对照。

> **实例**:一家公司自称"基座模型公司""AI算法公司",要按大模型公司的逻辑融资和估值。但财务预测里毛利率是 60-65%。
> → 60%的毛利与轻资产高复用软件叙事存在张力。
> → 需要按软件、硬件、渠道、实施和云推理拆分收入与直接成本。
> → 若拆分后主要毛利确由硬件和定制产生，再按相应业务实质选择可比公司。
> → 这直接决定了估值倍数应该给几倍,以及可比公司是谁。

**毛利拆分后的证据比单一毛利阈值更有价值。**

### 单位经济核算

- **API/token定价的现实检验**:声称的调用量 × 单价 = ?
  > 实例:37.5亿token × (1元/10万token) = **3.75万元**。一个被放在核心位置的"数据飞轮"指标,迄今创造的收入不到四万块。而且要进一步问:这些token是**付费消耗**还是**赠送额度**?(看控制台截图里的余额)
- **硬件的BOM与规模假设**:声称"成本可控制在1美元以下"——在什么出货量下?达到那个出货量需要什么?
- **CAC / LTV**:医疗B端的获客成本极高(销售周期12-18个月),deck通常完全不谈

## 3. 商业模式的自洽性

### 检查商业模式的内部矛盾

生物AI公司常见的自相矛盾:

| 矛盾 | 说明 |
|---|---|
| **"数据飞轮" vs 监管稳定性** | 模型持续更新会触发重新注册(见合规层)。**飞轮转得越快,证越拿不稳** |
| **"平台/基座" vs 项目制收入** | 每个客户都要定制开发,说明它不是平台,是外包 |
| **"轻资产算法" vs 低毛利** | 见上节 |
| **"端侧部署是核心优势" vs 只展示大模型性能** | 端侧的精度数据在哪? |
| **"卖芯片/模组" vs 资金计划里没有流片预算** | 承诺是画的 |
| **多产品线 vs 小团队** | 15个人做10条产品线,每条都做不深 |

### 资金用途 vs 承诺的核对

把 use of funds 的每一项,对照路线图的每一个里程碑。

> **实例**:融资用途是 服务器/数据50% + 团队33% + 市场17%。但路线图承诺2027年完成 **ASIC流片**。
> → **流片预算是0。**
> → 结论:要么ASIC是画的,要么资金计划是错的。**两者都是红旗。**

## 4. 竞争与护城河

(技术层的第3节做了技术对比,这里做**商业**层面的竞争分析)

### 4.1 被deck剔除的竞争者

**必须主动补上的三类:**

1. **平台方碾压风险(最致命)**
   问:如果手机厂商/芯片厂商/云厂商把这个功能做进底层免费提供,这家公司还剩什么?
   > 一家卖摄像头模组的公司若面临 SoC 厂商集成功能，需评估差异化、认证、渠道和切换成本；不能直接假设收入归零。
   **注意:deck有时会在别处自曝这个风险**(比如为了讲"卡脖子"故事,承认"核心专利被Apple掌握")——然后在竞品表里把Apple剔除。**逐字对照,抓这个矛盾。**

2. **在位者已经满足了刚需**
   问:客户的刚需现在是被谁满足的?这家公司提供的是**必需品还是加分项**?
   > 车载DMS(驾驶员监控)已经是红海,而法规要求的是**分心和疲劳**,不要求心率。也就是说车厂的合规刚需**已经被满足了**——你卖的是加分项。加分项在车厂供应链里的议价能力极弱

3. **非同类替代**:客户现在用什么解决这个问题?哪怕是个护士、一个Excel

### 4.2 护城河的真伪检验

对deck声称的每一条护城河,做**"大厂明天进场"压力测试**:

| 声称的护城河 | 压力测试 |
|---|---|
| 技术领先 | 领先多久?算法是论文还是know-how?对方追赶需要多久? |
| 数据 | 排他吗?(见技术层第4节)如果不排他,不是护城河 |
| 专利 | 授权了吗?权利要求覆盖什么?(见技术层第5节) |
| 客户关系 | 切换成本多高?是采购关系还是科研关系? |
| **先发注册证** | **✅ 这是真护城河**——它有时间壁垒且不可跳过 |
| 团队 | 不是护城河,人会走 |
| "全球唯一(+四个定语)" | 不是护城河,是话术 |

## 5. 估值、股权与条款

### 必查的算术

1. **post-money 一致性**:融资额 ÷ 出让比例 = post。和deck声称的估值对得上吗?
2. **本轮的估值和出让比例,deck说了吗?** 
   > **如果一份融资deck通篇讲了上一轮的估值,却不给本轮的估值和稀释比例——这本身就是一个信号。** 投资人最先看的东西,它却不给
3. **估值跳跃的依据**:从上一轮到本轮,估值涨了多少倍?这期间发生了什么实质进展来支撑?(拿到证?规模化收入?还是只是又过了一年?)
4. **累计稀释**:创始团队还剩多少?到下一轮/两轮后还剩多少?(创始人股份被稀释过度会影响长期动力)

### 股权结构与退出路径的绑定

- **VIE/红筹 vs 境内架构**:决定了能不能走A股。一家想上科创板的公司如果有VIE,路径要重搭
- **外资/FDI结构**:在医疗数据、人类遗传资源领域,外资背景会触发额外审批
- **对赌/回购条款**:有没有?(deck如果主动强调"无对赌无回购",这是加分项,但要看协议原文)
- **期权池**:预留了吗?(没预留意味着新投资人会被稀释)

## 6. 退出路径

**在生物赛道,必须显式回答:这家公司最终怎么退出?**

| 路径 | 前提 |
|---|---|
| **被大厂/械企/药企并购** | 最常见。但要问:**买家是谁?他们为什么要买而不是自己做?**(如果技术容易复制,他们会自己做) |
| **IPO(A股/科创板)** | 需要:境内架构 + 收入/利润门槛 + 通常需要注册证。**时间很长** |
| **IPO(港股/美股)** | 门槛不同,但医疗类需要清晰的产品/管线故事 |
| **License-out / 技术授权** | 在药和器械领域常见 |

**如果deck完全不谈退出,或者只说"我们要做成大公司"——追问买家画像。** 一个说不出潜在收购方的项目,退出路径是虚的。

## 7. PEVC 红队:三种视角的交叉攻击

写报告前,用三种不同的投资人视角各过一遍,看是否得出不同结论。**如果三种视角都说不投,那结论就很硬。**

### 视角A:成长型基金(看数字)
> "给我看重复性收入、留存、单位经济。POC不算数。你的收入曲线需要一个具名的大单来支撑——它在哪?"
> **最关心**:收入质量、增长的可持续性、毛利结构

### 视角B:早期科技基金(看技术与团队)
> "算法是不是真的领先?团队能不能做成?**如果这个技术跳跃不成立,你还剩什么?** 大厂做这件事的成本是多少?"
> **最关心**:技术壁垒的真实性、团队-任务匹配、大厂碾压风险

### 视角C:医疗专业基金(看监管与支付)
> "证在哪一步?谁付钱?有物价编码吗?销售周期多长?**你们进医院的4个案子,哪个付了钱、付了多少?**"
> **最关心**:监管路径、支付方、进院能力、临床证据等级

**这三个视角经常会打架**——比如B看好技术,C认为监管路径根本走不通。**把这个分歧写进报告**,它比一个统一的结论更有信息量。
