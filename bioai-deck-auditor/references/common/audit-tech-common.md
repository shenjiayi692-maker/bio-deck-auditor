## 1. 科学有效性 vs 工程有效性

这是生物+AI最重要的一条分界线,把它作为技术审计的第一个筛子。

一个技术宣称可能在三个层面上成立或失败,**而deck通常只证明了第一层,却在暗示第三层**:

| 层 | 问题 | 典型证据 | 典型失败 |
|---|---|---|---|
| **L1 科学可行** | 这件事在物理/生物学上可能吗? | 论文、机理 | 信号里根本不包含这个信息 |
| **L2 统计可行** | 在受控数据集上能达到多少? | benchmark、MAE、AUC | 只在自己的数据集上好 |
| **L3 工程可行** | 在真实部署条件下还成立吗? | 外部验证、前瞻性试验、端侧实测 | 换个人群/光照/设备就崩 |

**审计动作:对每一条性能宣称,问"这是L几的证据?"**

最常见的骗局是:用L1的论文 + L2的benchmark,去支撑一个L3的商业承诺。

> **实例**:一家公司声称"心率误差 < 0.7 BPM,端侧实时,医疗级"。心率误差0.7BPM大概率是L2(受控数据集上的最优结果)。但商业模式的落点是"0.5B模型跑在RK3588芯片上"——**这是L3,而deck从未给出蒸馏后的精度**。这个空白就是整份deck技术上最大的红旗。

**通用规则:凡是 deck 展示大模型性能、商业落点却是小模型/端侧，都应索要真实部署版本的精度、延迟、功耗和硬件约束。** 缺失时标为部署证据缺口，不推测公司为何未提供。

## 2. 性能宣称的解剖

### 2.1 "N+ 个指标" 是不是定义游戏?

生物信号领域最常见的注水方式:**从一路信号里推导出的所有统计量,被当成"N个独立指标"来数**。

审计方法:
- 问"这N个指标里,有多少个是**信息独立**的?"
- 一路脉搏波信号 → 心率、心率变异性的各种时域/频域参数(SDNN/RMSSD/LF/HF/pNN50...)。这些是**同一个信息的不同切法**,不是120个能力
- 竞品声称"10个指标"、它声称"120+",两者的**信息量差距可能远小于12倍**

**要求对方给出**:指标清单 + 每个指标的独立验证数据 + 哪些是从哪些推导出来的。

### 2.2 准确率数字的四个陷阱

**陷阱一:没有说在什么条件下。** 80-90%在什么人群、什么设备、什么光照、什么运动状态下?生物信号的性能对条件极度敏感。

**陷阱二:没有说和什么金标准比。** 无创估计的"准确",是和有创的真值比,还是和另一个无创设备比?后者毫无意义。

**陷阱三:开发集 vs 外部验证集混淆。** 这是临床AI最常见的问题。交叉验证 ≠ 外部验证 ≠ 前瞻性验证。deck经常用前者的数字冒充后者。
> 对照 TRIPOD+AI / PROBAST+AI 的要求:**开发、内部验证、外部验证必须分开报告**。

**陷阱四:捷径学习(shortcut learning)。** 模型可能没学到你以为它学到的东西。
> 经典例子:从人脸视频估计血压。模型可能根本没在读血流动力学,而是学会了从**年龄、性别、肤色、体型**去猜血压——因为这些人口统计学特征和血压确实相关。在训练分布内它表现很好,一旦换个人群就崩。
> **检验方法**:问对方做过**混杂因素消融实验**没有?如果把人脸打码只留皮肤区域,性能掉多少?如果在年龄/BMI分层内看,性能还在吗?

### 2.3 亚组/公平性检验(必问)

任何声称"跨人群通用"的生物AI,都必须提供**分层性能**:
- 肤色(Fitzpatrick分型)——这是光学生理测量的头号问题
- 年龄段(尤其老年人,血管顺应性变化极大)
- 性别
- 疾病状态(健康人 vs 患者。在健康人身上准,不代表在病人身上有用——而病人才是市场)
- 设备/环境(不同摄像头、不同光照)

**如果 deck 只给总体准确率、不给关键亚组，先标为高影响证据缺口。** 结合目标人群、已知公平性风险、监管要求和公司阶段决定是否升级红旗；不要在“没做”和“隐瞒”之间强行二选一。

### 2.4 Benchmark 的构造效度

审查deck里展示的任何性能曲线/scaling law图:
- 横轴纵轴分别是什么?
- **这个benchmark测的东西,和公司声称的能力是同一件事吗?**

> **实例**:一家生理感知公司用 MAFW/CelebV/UCF101(通用表情/视频/动作理解数据集)上的scaling曲线,来"验证"其**生理信号**技术路线的scaling law。这三个数据集里**没有任何生理真值标签**。它验证的是通用视频理解的scaling,不是生理感知的。这是构造效度的偷换。

## 3. 与现存技术的真实对比

### 3.1 把 deck 竞对表视为待核实的公司观点

系统性地检查三件事:

**① 谁被剔除了?** 最危险的竞争者往往不在表里。检查是否遗漏了:
- **平台方/大厂**:如果功能可能被手机、芯片或云厂商集成，评估价格压力、差异化、认证、数据权利和切换成本；不要未经分析就假设商业模式归零
- **在位者**:该场景里已经有人在赚钱吗?他们的方案够用吗?
- **非同类替代**:客户现在用什么解决这个问题?哪怕是个Excel表或一个护士

**② 对比维度是不是精心挑选的?** 如果一家公司在自己选的8个维度上全赢,这8个维度就是被反向设计出来的。问:**按客户真正在乎的维度排,谁赢?**

**③ 自相矛盾。** 竞对表里经常出现内部打架:自己列"准确率80-90%"、竞品Philips列"医疗级",然后在页面另一处宣称"全球唯一医疗级"。**逐字对照,这类矛盾很常见。**

### 3.2 "唯一/首个"的审计

deck酷爱"全球唯一""国内首个"。每一个都要追问:**唯一性的定语有多长?**

> "全球唯一同时具备 端侧 + 医疗级 + 多指标 + 全产业链 的玩家"
> —— 加四个定语之后,任何公司都可以是"唯一"。这不是护城河,这是话术。

**真正的护城河检验**:如果一个资源充足的竞争者(比如某大厂)明天决定做这件事,**什么东西会挡住他?** 
- 专利?(查——见第5节)
- 数据?(见第4节)
- 客户锁定/切换成本?
- 监管许可(先发注册证是真壁垒)?
- 还是……什么都挡不住,只是他们暂时没兴趣?

**"我们比他们早两年"不是护城河。**

## 4. 数据壁垒的真伪

"我们有100T数据"经常被当作护城河，但数据量本身不足以证明权利、标签质量、独占性或模型增益。

**数据成为壁垒的四个必要条件**(缺一不可):

1. **排他性**:别人拿不到。和医院签的是"合作协议"还是"排他协议"?如果是前者,同一家医院明天可以和你的竞争对手签同样的协议
2. **标注质量与真值来源**:生物数据的价值在于**配对的金标准真值**。有100T视频但只有1000例有动脉血压真值,那有效数据量是1000
3. **分布覆盖**:数据的多样性(人群、疾病、设备、环境)比总量重要得多。100T同质数据不如1T多样数据
4. **合规可用于商业训练**:见合规层。医院数据用于商业模型训练,需要伦理审查 + 知情同意覆盖 + 数据出境/使用范围的明确授权。**很多公司的数据在法律上根本不能这么用**

**审计动作**:要求看数据协议的**使用范围条款**和**排他性条款**。这两条决定了数据到底是不是资产。

**反向检验**:如果数据真的是壁垒,那么**数据的边际收益递减在哪里?** 一个成熟的团队应该能回答"再加10倍数据,性能提升多少"——如果答不上来,说明他们没有真正在数据上做过实验,数据叙事是事后编的。

## 5. IP 与 FTO(自由实施)

生物/医疗领域专利壁垒极高,这一层不能跳过。

**审计动作:**

1. **专利"受理" ≠ "授权"。** 受理只证明申请已提交，价值取决于权利要求、授权可能性、申请人、地域和 FTO；不要把申请数直接等同壁垒。
2. **核心专利在谁手里?** 如果deck自己承认"该领域核心专利主要由某几家外国公司掌握"(有些deck会为了讲"卡脖子"故事而这么写),那它同时也承认了**自己有FTO风险**——而且通常没有给出应对方案。这是一个很好的撬点
3. **出海风险**:如果商业计划包含海外市场,FTO问题会立刻变成实质法律风险
4. **算法专利的实际效力**:纯算法/软件专利在很多司法辖区保护力很弱。不要高估

**待核实项**:专利号必须外部核查(国家知识产权局/Google Patents)。deck里的专利证书图片经常是打码的,或者是"受理通知书"而非"授权公告"。

## 6. 叙事跳跃检测(本skill的核心武器)

生物+AI deck 最危险的操纵,不是伪造数据,而是**在真实的技术能力和宏大的商业叙事之间,做一次或多次未经论证的跳跃**。

**方法:画一条链条,把deck的叙事拆成步骤,然后逐步问"这一步的依据是什么?"**

> **实例拆解**
> deck叙事:`rPPG心率算法` → `120+生理指标` → `人类理解基座模型` → `具身智能生命感知基座` → `世界模型`
>
> 逐步审问:
> - 心率 → 120指标:**同一路信号的重排**(见2.1)。跳跃1
> - 生理指标 → "理解人类":生理信号能反映唤醒度,但"理解"包含意图、语境、心理状态。**从生理到心理的推断在心理学上高度争议**。跳跃2
> - 人类理解 → "基座模型":基座模型的定义是可迁移的通用表征。一个心率算法不因为叫"基座"就变成基座。跳跃3
> - → "世界模型":纯粹的热点词嫁接。跳跃4
>
> **结论**:技术底子(L1的rPPG心率)可能是真的,但支撑估值的是跳跃3和4,而它们没有任何证据。

**跳跃的常见形态:**
- **术语升级**:把一个具体的算法重命名为一个更宏大的品类("检测模型"→"基座模型"→"世界模型")
- **能力外推**:在A任务上work,就声称在B任务上也会work(没有跨任务的实证)
- **热点嫁接**:把当下最热的概念(大模型、具身智能、Scaling Law、Agent)贴到一个不相干的技术上
- **单点验证泛化**:一个指标(心率)验证过,就让整个指标体系(含血压、疾病)搭便车

**每识别出一次跳跃,就问一个问题:如果这次跳跃不成立,商业模式还剩什么?** 通常剩下的那个东西,才是这家公司的真实估值锚。

## 7. 团队-技术匹配度

不看简历光鲜度,看**做成过没有**。

**把路线图上的每一个承诺,映射到团队里的具体的人:**

| 路线图承诺 | 需要什么经验 | 团队里谁有? |
|---|---|---|
| 拿医疗器械注册证 | 做过器械注册(RA) | ? |
| 芯片流片(ASIC) | 做过流片 | ? |
| 进车厂供应链 | 车规级量产经验 | ? |
| 医院销售 | 医疗渠道 | ? |
| 大规模模型训练 | 训过大模型 | ? |

**如果一个承诺没有对应的人,这个承诺就是画的。**

**其他信号:**
- 团队规模 vs 战线数量。15个人同时做云端API、SDK、整机、模组、FPGA、ASIC、医院、车企、机器人、玩具、眼镜——**这不是全产业链优势,这是焦点缺失**。早期公司死于铺得太开的概率远大于死于做得太窄
- **顾问是否打码**。给投资人的材料里把首席科学家名字写成"×××",非常反常。要问:有股权绑定吗?每周投入几小时?还是纯挂名?
- **学术团队做产品**:强学术背景 + 零产业化经验,是生物AI的高频失败模式。学术追求novelty,产品追求robustness,两者的激励是相反的
