# 合规层审计:监管路径即商业路径

> **为什么这一层单独存在**
> 通用的VC尽调框架把"合规"当成一个风险附注。在生物/医疗赛道,这是错的。
> **监管路径会直接影响现金流曲线、上市时点、竞争壁垒和估值模型。** 若预测收入依赖特定受监管用途而产品无法取得所需许可，该部分预测不成立；不依赖该用途的收入需另行判断。
> 注册证能降低准入不确定性，但是否形成护城河还取决于适用范围、临床证据、竞品数量、支付、渠道和变更管理。
> 所以在生物赛道,合规不是风控项,**它就是商业模式本身**。

## 1. 第一问:这是不是医疗器械?

**这是整个尽调里最有杠杆的一个问题。** 答案不同,公司的估值模型、时间表、壁垒完全不同。

### 判定的核心是"预期用途"(intended use),不是技术

同一个算法,取决于它**声称自己干什么**,可以落在完全不同的监管框架里:

| 宣称 | 大概率定性 |
|---|---|
| "记录你的运动心率,仅供健身参考" | 消费电子 / 健康类产品(通常不受器械监管) |
| "监测心率,用于**辅助诊断**心律失常" | **医疗器械** |
| "输出血压值" | **医疗器械**(血压测量是明确的器械功能) |
| "预测10种心血管疾病风险" | **医疗器械**(疾病风险预测=诊断辅助) |
| "疾病早期筛查" | **医疗器械** |
| "替代传统抽血检测" | **医疗器械**(而且是高风险类别) |

**审计动作:把deck里所有描述产品用途的动词圈出来。**
"监测""筛查""诊断""预测疾病""评估病情""替代检查"——**每一个都是监管触发词**。

⚠️ **关键陷阱:公司可能在不同材料里说不同的话。** 对投资人说"我们做疾病筛查、替代抽血"(为了讲大故事),对监管说"我们是健康管理软件"(为了不受管)。**这两套说辞不能同时为真。** 找到这个矛盾,是这一层最重要的产出。

### 检查:deck里出现过"注册证"三个字吗?

如果一家公司:
- 声称输出诊断级/医疗级指标,**且**
- 已经在向医院销售设备或提供检测服务,**但**
- 全篇没有提到任何注册证/临床试验/注册路径

**这是高优先级核实项。** 可能原因包括产品不受器械监管、仍处科研阶段、材料遗漏、分类理解错误或无证经营。先取得预期用途、销售合同和分类/注册依据，再决定红旗等级。

## 2. 中国路径(NMPA)

### 器械分类与时间/成本量级

| 类别 | 风险等级 | 管理方式 | 周期/成本核实方式 |
|---|---|---|---|---|
| **一类** | 低 | 备案 | 查具体产品备案要求和所在地实践 |
| **二类** | 中 | 省级药监部门注册 | 按同品种、临床评价路径、补正和当地审评实践估算 |
| **三类** | 高 | 国家药监部门注册 | 按分类、临床试验要求、中心/样本量和沟通记录估算 |

独立软件（SaMD）可能构成医疗器械，按预期用途、功能和风险分类。不得把“辅助诊断”四个字机械映射到固定类别，应查当期目录、分类界定和同品种。

**审计动作:**
1. 按预期用途,推断它**应该**是几类
2. 对照它的路线图和资金计划——**时间和钱对得上吗?**
3. 若明年收入依赖受监管医疗用途而注册尚未启动，将该收入标为缺乏监管支撑，并检查是否存在可合法实现的其他用途或合作模式。

### 中国特有的注意点

- **AI医疗器械**有专门的审评要点(算法可解释性、数据集代表性、更新管理)。**算法迭代本身可能触发重新注册**——这对"持续学习/数据飞轮"的商业叙事是一个结构性冲突:**你的模型越是持续更新,你的注册状态越不稳定。** deck通常没有意识到这个矛盾
- **进院流程**:拿到证 ≠ 能卖。还要过医院准入、招标、预算和支付路径。独立医疗服务价格项目只是可能路径之一；也可能进入设备采购、信息化预算、打包支付或成本节约模型。必须按具体产品核实
- **科研合作 ≠ 商业销售**。很多公司用"科研设备""横向课题"的名义进医院,这在监管上是灰色的,而且**不能规模化**

## 3. 美国路径(FDA)

如果deck包含出海计划,必须审这一层。

| 路径 | 适用 | 周期 |
|---|---|---|
| **Exempt / General Wellness** | 一般健康类,不作疾病声称 | 无需审批 |
| **510(k)** | 有实质等同的前代产品 | 数月-1年+ |
| **De Novo** | 新型、中低风险、无对照品 | 1年+ |
| **PMA** | 高风险 | 数年,需临床试验 |

**关键点:FDA 的 "General Wellness" 豁免有严格边界——一旦做出疾病相关声称,豁免立即失效。**

**特定领域的硬门槛(必查):**
- **血压测量**:任何声称输出血压值的设备,需满足血压计的性能标准(如 ISO 81060-2 / AAMI)。这是一个**明确的、可验证的技术门槛**
- **心电/心律失常检测**:有明确的审评先例和性能要求
- **AI/ML 器械**:FDA 有针对算法变更的预定变更控制计划(PCCP)框架——同样,**持续学习和监管稳定性有内在张力**

## 4. 监管如何反向决定财务模型

**这是本层最重要的一节。** 把监管结论翻译成财务后果:

### 4.1 现金流时点

```
未取得目标用途所需许可 → 只能在合法的科研、非医疗或其他适用范围内开展业务
     ↓
启动注册（周期、成本及期间收入按产品核实）
     ↓
拿证 → 才能真正开始医疗市场的销售
     ↓
支付路径 + 医院准入（周期按地区、预算和采购方式核实）
     ↓
规模化收入
```

**对照 deck 的收入曲线**:若预测依赖受监管医疗用途，而注册尚未启动，该部分收入缺乏监管支撑。另行检查是否存在合法的消费、科研、海外或非医疗收入，不要把所有收入一并归零。

### 4.2 支付方问题(比市场规模重要得多)

deck 总爱写“XX 万亿市场”。若没有付款方、预算科目和可及患者口径，这个数字不能直接支持收入预测。

在医疗里,**用户 ≠ 决策者 ≠ 付款方**,三者经常是三个人:
- 患者用,医生决定,医保付
- 或者:医院买,科室用,患者自费

**审计问题:**
1. 这个产品,**谁签支票**?
2. 医院通过什么路径收回成本或获得预算?独立收费、医保、设备采购、信息化预算、打包支付还是效率节约?
3. 如果是自费市场——支付意愿被验证过吗?(不是"愿意试用",是"愿意付钱")
4. 如果是B端卖给医院——**医院的预算从哪一项出?** 设备采购?信息化预算?科研经费?(科研经费=一次性,不可持续)

**"我们已经进了4家三甲医院"** 这句话必须被追问到底:进去的是**科研合作**还是**采购**?付了多少钱?**是一次性还是可复制的?**

### 4.3 销售周期的残酷性

医疗B端销售是出了名的慢:
- 医院企业级销售周期可能较长；用公司实际线索到签约、验收和回款的 cohort 数据替代固定行业数字。
- **Pilot Purgatory(试点炼狱)**:POC签了一堆,但没有一个转化为规模采购。这是医疗AI公司最常见的死法
- **审计动作**:数一数deck里的POC/试点数量,再数已转化的规模订单数量。**转化率是多少?** 如果POC很多但零转化,这是 🟠 严重红旗

### 4.4 估值模型的调整

一家未获证的医疗AI公司,**不能用SaaS的估值倍数**。它的正确类比是:
- 拿证前:类似临床前生物科技公司(按里程碑估值,高风险)
- 拿证后:才具备SaaS/器械公司的估值逻辑

**如果deck按SaaS逻辑要估值,但公司实质处于"拿证前"阶段——这是估值模型的错配,而且是最贵的一种错误。**

## 5. 数据合规

### 中国

- **《个人信息保护法》**:人脸、生物识别、医疗健康数据均属**敏感个人信息**,需要**单独同意**,且要做个人信息保护影响评估
- **《人类遗传资源管理条例》**:涉及基因/遗传信息的,有严格的采集、保藏、利用、对外提供的审批要求。**外资背景的公司尤其敏感**
- **医院数据用于商业模型训练**:这是最容易踩雷的地方。需要:伦理审查通过 + 知情同意的范围覆盖"商业用途" + 数据脱敏 + 明确的数据使用协议
- **数据出境**:如果有境外主体/境外服务器,涉及数据出境安全评估

**审计动作:如果一家公司把"我们从医院回流了100T数据"当成核心资产来讲,你必须问:**
1. 伦理审查批件有吗?
2. 知情同意书里,有没有覆盖"用于商业产品开发"?
3. 数据的所有权/使用权在协议里怎么约定的?医院是不是保留了所有权?
4. 有没有数据出境?

**如果这些答不上来,那"100T数据"不是资产,是负债。**

### 欧美

- **GDPR**:健康数据是特殊类别数据,处理门槛高
- **HIPAA**(美国):PHI 的使用和披露规则
- **欧盟 AI 法案**:医疗 AI 是否属于高风险系统取决于用途、法规地位和适用时间点；结合 MDR/IVDR 与当期实施时间表核实。

### 特殊警示:摄像头类产品

如果产品在**车内、家庭、母婴、养老**场景持续采集人脸/生理数据,隐私敏感度极高。这不仅是合规风险,**也是市场风险**——一次隐私事件足以杀死一个消费品牌。

## 6. 伦理与临床研究合规

deck里如果出现"我们在医院做了临床验证/万人级验证":

**必问:**
1. 有**伦理委员会批件(IRB/EC)**吗?
2. 研究在 **ClinicalTrials.gov 或中国临床试验注册中心**注册了吗?(可外部核实!)
3. 是**前瞻性**还是回顾性?(前瞻性的证据等级高得多)
4. 是**外部验证**还是在自己的数据上做的内部验证?
5. 有没有发表?(未发表的"万人级验证"可信度打折)

**"万人级临床验证"这个说法本身要警惕。** 一万个人做了什么?
- 一万人用过 → 这是用户量,不是验证
- 一万人有配对金标准真值 → 这才是验证(而且成本极高,要问钱从哪来)

**这两者的区别是数量级的,而deck经常故意模糊。**

## 7. 常见的"绕开监管"话术及其风险

deck和创始人会用这些说法来化解你的监管质疑。**每一条都要知道它的破绽:**

| 话术 | 破绽 |
|---|---|
| "我们只做健康管理,不做诊断" | 那你deck里的"疾病预测""筛查""替代抽血"怎么解释?**两套说辞不能同时为真** |
| "我们是卖给医院做科研的" | 科研用途的市场、预算与重复采购逻辑不同于临床用途；要求收入预测只覆盖合法适用范围并用订单验证。 |
| "我们只提供算法,器械资质由客户方拿" | 部分成立,但这意味着**你的商业模式高度依赖客户的注册进度**,而且你在价值链里的地位很弱(变成了一个组件供应商) |
| "先做海外,海外监管宽松" | 通常相反。FDA/CE/MDR 都不宽松,而且你还要叠加FTO风险 |
| "等有收入了再去注册" | **顺序反了。** 没证的收入本身就是风险敞口 |
| "我们的证在申请中" | 问:**受理号是什么?**(可查)什么阶段?临床做完了吗? |

**最后的检验**:让公司画出**从今天到第一笔合规的规模化医疗收入**之间的完整路径,标出每一步的时间和钱。

**如果他们画不出来,或者画出来的时间线和融资计划对不上——这就是这份deck最深的那个洞。**
